# 🐦 Twitter Database Simulation

A detailed SQL database design that simulates Twitter's backend architecture.

## 📌 Project Overview
This project models the core data structure of Twitter, including user interactions, posts, followers, and engagement metrics.

## 🛠️ Features & Tools
* **Database Engine:** MySQL
* **Tools:** MySQL Workbench
* **Key Components:**
  * Entity-Relationship Diagrams (ERD)
  * Complex relational constraints & Foreign Keys
  * Optimized queries for user feeds, followers, and interactions
