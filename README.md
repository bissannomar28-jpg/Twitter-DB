# 🐦 Twitter Database Simulation

A detailed SQL database design that simulates Twitter's backend architecture.

## 📌 Project Overview
This project models the core data structure of Twitter, including user accounts, tweets, follower dynamics, and database relationships.

## 🛠️ Features & Tools
* **Database Engine:** MySQL
* **Tools:** MySQL Workbench
* **Key Components:**
  * Relational schema for `users`, `tweets`, and `follows` tables
  * Foreign key constraints ensuring strict data integrity
  * Primary keys with auto-incrementation
  * Unique indexing for handles and email addresses
